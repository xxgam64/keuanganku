Baca Riwayat Mutasi (transactions:read)

Tanpa Izin Transaksi / Debet Dana

Aplikasi ini tidak memiliki izin dan tidak dapat melakukan transfer, penarikan, atau pemindahan saldo perbankan.

PIN m-banking dan password akun Anda tidak pernah diminta, diakses, atau disimpan di server mana pun. Otorisasi dilakukan via pertukaran token enkripsi AES-256 berotasi 30 hari.
