Konfigurasi Database Diperlukan!

Karena Anda mengaktifkan fitur Login & Simpan Cloud, Anda perlu menghubungkan aplikasi ini ke database gratis (Firebase).

  1. Buka Firebase Console dan buat Project baru.
  2. Tambahkan aplikasi Web (ikon </>) ke project Anda.
  3. Aktifkan Authentication (Pilih Email/Password).
  4. Aktifkan Firestore Database (Mulai dalam Test Mode).
  5. Salin kode firebaseConfig yang diberikan Firebase, lalu cari bagian "KONFIGURASI FIREBASE ANDA DI SINI" di dalam file HTML ini (sekitar baris paling bawah) dan ganti kodenya.
  6. Simpan file dan upload kembali ke GitHub!

Pesan ini akan hilang otomatis setelah konfigurasi diisi dengan benar.
